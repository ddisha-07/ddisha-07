## 🧠 Mentora — Knowledge Beyond Boundaries

> AI-powered personalized learning that adapts to the learner.

Mentora is an intelligent learning platform designed to make learning **personalized, engaging, and relevant** through AI-powered experiences.

Instead of traditional long-form courses, Mentora introduces **Learning Journeys** powered by bite-sized **Learning Bites** that can be completed in just a few minutes.

### ✨ Features

* 🗺️ Personalized Learning Journeys
* 🧩 2–5 minute Learning Bites
* 🤖 **Kai — AI Learning & Knowledge Assistant**
* 🔥 Daily learning streaks
* ⭐ XP-based progression
* 🏆 Leaderboards & gamification
* 📊 Learning progress tracking
* 🌍 Multilingual AI assistance
* 🧠 AI-powered personalization

**Tech & Focus:** `AI/ML` `Generative AI` `React` `Supabase` `Personalized Learning` `Gamification`
